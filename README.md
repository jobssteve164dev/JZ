# 吴江科三 · C2 路线练习

[在线练习](https://km3.szlk.uk)

基于考点图的一号、九号、十号线 3D 自动挡驾驶练习。每条路线 3 公里，包含起步前灯光、路线提示、转向与减速操作、交通信号和停车复盘。

## 使用

选择路线和带提示练习 / 模拟考试 / 跟随学习，完成上车准备与随机五题灯光，再驶向终点。跟随学习会自动驾驶，沿途用语音讲解全部考点与操作要点，可暂停、切换驾驶位或跟车视角。道路按原图分段显示车道增减、路口分流和白色导向箭头；一号线起步道路三车道到路口四车道、首次右转后两车道到末端三车道分别还原。三条路线的变道、超车、回位与路口转向均检查实际车道，具体对应见 [车道对齐记录](docs/LANE_ALIGNMENT.md)。

单练灯光每次打乱十九条口令。上下拖动灯杆末端旋钮：向上依次切换至示廓、前照灯，向下逐档关闭；上推杆身锁定远光，再推恢复近光；下拉闪光、松手回位，连续两次完成远近光交替。危险报警灯使用独立三角开关。练习作答不限时；模拟考试听完口令后须在五秒内完成正确操作，到时判定。每题判定后至少等待五秒再切换下一题。键盘可聚焦旋钮或杆身按上下键操作。

手机可添加到主屏幕，横屏触摸操作；首次完整加载后可离线练习。Android 支持时自动全屏及锁定横屏，iOS 由用户横放手机。语音使用设备的中文朗读服务。

键盘：W / ↑ 油门，S / ↓ / 空格刹车，A / D 或 ← / → 转向，Q / E 转向灯，Z / C 观察左右后方。手机支持同时按油门和转向；松开方向控制自动回正。

车身上的前后转向灯会同步闪烁，踩下刹车点亮后方刹车灯与高位刹车灯，松开即熄灭。驾驶画面中的“灯光”可操作同一套仿真灯杆，控制前照灯、示廓灯与双闪；远近光具有不同照射距离，尾灯和刹车灯分别显示。

## 本地运行

```sh
npm ci
npm run dev
```

生产构建：`npm run build`；预览：`npm run preview`。

## 验证

`npm test` 覆盖路线顺序、长度、车辆操作、灯光、评分与三条完整驾驶。`npm audit --audit-level=high` 检查依赖，`npm run build` 生成最终页面和离线缓存。CI 与 Security 工作流不会自动部署。

## 部署

Cloudflare Workers 静态资源，域名 `km3.szlk.uk`。在受控环境设置 `CLOUDFLARE_API_TOKEN` 与 `CLOUDFLARE_ACCOUNT_ID`，构建并验收后运行 `npm run deploy`。不在仓库保存凭据。

## 资料与边界

路线以 `input/` 三张原图为依据，十号线采用图中手写考点；灯光采用第四张“苏州观山科目三考场”图的十九条口令。分段距离、道路外观、信号周期和感应容差为训练参数，不是考场测绘或官方评分系统。游戏不能代替实车培训。规则来源与实现边界见 [设计说明](docs/IMPLEMENTATION.md)。
