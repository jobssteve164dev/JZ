# 吴江科三 · C2 路线练习

[在线练习](https://km3.szlk.uk)

基于考点图的一号、九号、十号线 3D 自动挡驾驶练习。每条路线 3 公里，包含起步前灯光、路线提示、转向与减速操作、交通信号和停车复盘。

## 使用

选择路线和练习 / 模拟考试模式，完成上车准备、模拟灯光，再驾驶到终点。手机可添加到主屏幕，横屏触摸操作；首次完整加载后可离线练习。Android 支持时自动全屏及锁定横屏，iOS 由用户横放手机。

键盘：W / ↑ 油门，S / ↓ / 空格刹车，A / D 或 ← / → 转向，Q / E 转向灯，Z / C 观察左右后方。手机支持同时按油门和转向；松开方向控制自动回正。

## 本地运行

```sh
npm ci
npm run dev
```

生产构建：`npm run build`；预览：`npm run preview`。

## 验证

`npm test` 覆盖路线顺序、长度、车辆操作、灯光、评分与三条完整驾驶。`npm audit --audit-level=high` 检查依赖，`npm run build` 生成最终页面和离线缓存。CI 与 Security 工作流不会自动部署。

## 部署

Cloudflare Workers 静态资源，域名 `km3.szlk.uk`。在受控环境设置 `CLOUDFLARE_API_TOKEN` 与 `CLOUDFLARE_ACCOUNT_ID`，构建并验收后运行 `npm run deploy`。不在仓库保存凭据。

## 资料与边界

路线以 `input/` 三张原图为依据，十号线采用图中手写考点；灯光采用第四张“苏州观山科目三考场”图的十九条口令。分段距离、道路外观、信号周期和感应容差为训练参数，不是考场测绘或官方评分系统。游戏不能代替实车培训。规则来源与实现边界见 [设计说明](docs/IMPLEMENTATION.md)。
