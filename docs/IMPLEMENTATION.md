# 吴江 C2 科目三模拟

## 交付合同
按用户提供的一、九、十号线图片构建可操作 3D 路线游戏；每条 3000m，正常训练约 15 分钟；Cloudflare / km3.szlk.uk；GitHub 采用 SZLK 的 jobssteve164dev 身份。禁止以通用随机路线代替三条原图。保留原图、用户文件和 SoloMap 状态。

## 实现与验收
- Three.js + Vite，静态制品由 Cloudflare Workers Assets 提供；不引入登录或数据库。
- 路线定义、车辆物理、评判、三维场景、界面分离。C2 D/N/P、驻车制动、安全带、左右观察、灯光模拟、转向灯、油门、制动、方向盘。
- 练习模式：路线引导、操作提示、错误后可继续；考试模式：关闭引导和无语音考点提示，完整结束后复盘。暂停冻结物理、计时、信号和打灯时间。15分钟是练习参考，不做超时淘汰。
- 图片是示意图，不包含经纬度、分段里程、路宽、实景外观与信号周期。保留拓扑、行驶方向、路口/灯位和项目顺序；路段按总长 3000m 标定；路宽、建筑和信号配时仅用于模拟，不声称测绘复刻。
- 单元验证覆盖三条路线长度、项目次序、车辆操作、信号、计分和终点停车；最终构建脚本语法、真实浏览器桌面/手机、三条完整驾驶回放、无页面错误。独立审查通过后提交发布。
- CI：push main/PR 执行 npm ci/test/build；Security 同分支和计划任务执行 npm audit。无自动部署。正式发布 npm run deploy，仅上传 dist；本地凭据不写仓库。

## 会车、超车与声音

会车5秒和超车150米采用用户指定的训练要求，不冒称吴江官方评分参数。会车在起点前40米预告，从“开始会车”位置开始计时5秒，在原车道内小幅靠右，通过会车点后播报结束与回正，检查减速、观察、靠右和回正；超车按实际行驶距离限制150米，回位前播报并检查右灯满三秒及重新观察。路口直行、左转、右转均检查制动。法规动作依据为[道路交通安全法实施条例第47、48条](https://xzfg.moj.gov.cn/mobile/law/detail?LawID=75)，原图未给出实车安全距离或时间参数。

发动机音效使用浏览器音频合成，随油门和车速变化，语音播放时压低音量；暂停、后台或退出驾驶时静音。无外部音频下载。

一号线会车与超车起点相隔约143米，超车轨迹与项目一起后移，保持掉头→会车→超车→路口顺序和原车道关系。九号、十号两项目原本相隔较远，不移动位置。跟随学习在会车、超车操作尚未结束时不插入下一项目讲解。

左右转向灯在车辆移动、同向实际转向且方向盘超过小幅修正后，检测回正或反打自动关闭；打灯等待和微调不关闭，换侧打灯重置转向记录。跟随学习不会在自动回灯后反复重新打灯。

速度判定从实际进入项目区域开始，提前减速路段仍检查制动与观察，但不把减速前的最高车速计作通过时超速；进入区域后才降速仍会记录超速。

路口的判定区域与3D路面交叉区域一致，左右转和直行均在驶出路口后结算观察；转向灯仍须在进入路口前开启满三秒。左、右转按低于30km/h判断，不再使用25km/h阈值。
